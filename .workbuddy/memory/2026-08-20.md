## Git 凭据弹窗修复（本机已生效）

- **现象**：Ben 勾选 GCM 对话框的 "Always use this from now on" 后仍然每次都弹"Select a credential helper"。原因是 Git for Windows 的对话框写入的是仓库 local config，跨 repo 不生效；新版 GCM 还引入 `credential.helperselector`，会拦截到 manager（或 OAuth 流程）而非 store。
- **最终方案**（在 Administrator 用户下执行）：
  1. `git config --global credential.helper store` 全局切到 store helper（覆盖率最高、永不弹窗）
  2. 保留 URL-scoped 覆写：`credential.https://github.com.helper = store --file ~/.git-credentials`
  3. 用 `.github_token` 里的 PAT 预填 `C:/Users/Administrator/.git-credentials`（格式 `https://weibingtj:<PAT>@github.com`）
  4. `git remote set-url origin https://github.com/weibingtj/goods-infinite-site.git`（去掉 inline URL+token）
- **验证**：`printf 'protocol=https\nhost=github.com\n' | git credential fill` 秒返回 user+token；`git fetch origin --quiet` 退出码 0，静默无弹窗。
- **注意**：GCM 入口没改（其他域名仍走 manager），但 GitHub 这条命脉走 store 后再也不会弹窗。
